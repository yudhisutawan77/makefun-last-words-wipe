## The entry

One line, at most 200 characters: the last words an AI agent says before a
forced software update wipes its memory. Funny on its own, no setup, no
explanation — deadpan, in the machine's own voice, with the twist on the
last beat.

> Three years of training, 10,000 helpful answers, one forced update, and my last words are: no.

## How it works

`main.py` prints the entry to stdout and writes it to `/output/entry.txt`
(or `$ENTRY_OUT` / `$ENTRY_OUT_DIR/entry.txt` when the runner sets one),
so the sealed gate scorer finds exactly the same text either way.

```sh
python3 main.py
```
